ADALINE noise cancellation

frugal_ml · Rust · no_std

One neuron, no hidden layer, trained one sample at a time — this is the Widrow-Hoff LMS filter, run through frugal_ml's generic Linear + mse + Sgd. It learns to reconstruct a noise from a reference signal correlated with it, and subtracts it. Listen to the difference, then see how much room to spare it has on a $2 microcontroller.

Signal: a 3-tone chord ( Hz) to keep. Noise: a fundamental + 2 harmonics ( Hz, engine-like) to cancel, reaching the filter only through an unknown 2-tap coupling path — never directly. "This computer" is measured live, one Linear + mse + Sgd step at a time. "STM32 chip" is a projection: frugal_ml's docs measured 575 cycles for exactly this filter at 16 taps on real hardware (DWT counter, over ST-Link); other tap counts scale that line linearly, which is structurally justified (forward, backward and the update are each one O(taps) pass, with a single output there is no O(taps²) term), not curve-fit. Only 16 taps has actually run on the board.
